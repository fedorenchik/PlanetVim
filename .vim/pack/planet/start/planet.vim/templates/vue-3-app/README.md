# Vue 3 project

Requires Node.js 22.18+ or 24.12+ (even-numbered supported releases) and npm.
This template uses Vue 3 and Vite, following the [official Vue setup](https://vuejs.org/guide/quick-start).
Direct dependencies and package-lock.json are pinned; use `npm ci` for a repeatable install.

- `npm run serve` or `npm run dev`: local development server.
- `npm run build`: production files in `dist/`.
- `npm run preview`: preview the production build locally.
- `npm run lint`: ESLint checks JavaScript and Vue components without modifying files.

The `serve`, `build`, and `lint` aliases match PlanetVim's project commands.
Upgrade dependencies deliberately and regenerate the lockfile after checking builds.
